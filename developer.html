Fácil is designed and built by ItsNobodyX, a developer focused on small, fast, privacy-respecting tools that run entirely in the browser. The project reflects a straightforward preference: software that does a specific job well, keeps the user's data on the user's device, and stays out of the way.

About the build

Fácil is a static, client-side application with no backend, no database, and no server-side processing. It can be hosted on any static host. The interface is intentionally minimal, and every visible control performs a real operation on your device.
